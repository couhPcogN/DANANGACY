# Backend DANANGACY

Thư mục dành cho backend Python + FastAPI trong repository chung với frontend tại `../DANANGACY/`.

Hiện chưa có mã nguồn backend, dependency hoặc lệnh chạy server. Frontend đang dùng dữ liệu demo cục bộ và chưa kết nối API thật.

Kiến trúc dự kiến: **API Router → Service → Repository → SQLAlchemy → PostgreSQL**.
