# Tính năng DANANGACY

| Tính năng | Frame | Hành vi tối thiểu |
|---|---|---|
| Xác thực | A01–A06 | Chào mừng, đăng nhập/đăng ký mẫu, quên và đặt lại mật khẩu ở UI |
| Trang chủ | Home trước/sau, C01 | Thời tiết mẫu, lịch sắp tới, gợi ý địa điểm, thử thách |
| Khám phá | Explore, B01–B06 | Tìm/lọc, chi tiết, lưu yêu thích, bản đồ minh họa |
| Lịch trình | C01–C07J | Tạo 3 bước, xem lại, lưu, chi tiết, chỉnh sửa và cảnh báo hợp lệ |
| Thời tiết | D01–D03 | Xem cảnh báo, chọn địa điểm trong nhà, xác nhận thay thế |
| Mini game | E01–E05 | 5 câu, trạng thái chọn/xác nhận, kết quả và xem lại |
| Phần thưởng | F01–F04 | Xem điểm, đổi ưu đãi giả lập, xem mã đã đổi |
| Hồ sơ | G01–G03A | Sửa tên/điện thoại, xem mục liên quan, yêu thích/trống |

File Figma có cấu trúc màn hình, component và style; bản đọc hiện tại không có hợp đồng API hay quy tắc xác thực thật. Các hành vi trên là diễn giải nhất quán từ chuỗi frame để làm bản demo có thể dùng. Khi có spec sản phẩm, cập nhật bản đồ tương tác trước khi nối dịch vụ.
