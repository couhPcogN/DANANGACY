# TASK 01 — Android Studio Foundation, chỉ làm một PR

**Feature:** App foundation | **Scope:** `frontend/app/**` | **Mode:** UI-first, no backend.

## Before coding

- Inspect the actual local project generated by Android Studio: `settings.gradle.kts`, root and module `build.gradle.kts`, `gradle/libs.versions.toml`, Manifest, `MainActivity.kt`, theme and source sets.
- Read `frontend/app/AGENTS.md`, `docs/frontend/app-architecture.md`, `docs/frontend/coding-conventions.md`, `docs/frontend/frontend-testing.md` and `frontend/app/docs/AI_WORKFLOW.md`.
- Detect existing Kotlin/AGP/Compose BOM/JDK versions from the local files. Never paste invented Gradle versions or blindly replace the Studio-created project.
- Before modifying source, provide a brief file-by-file plan. Reuse or extend existing theme/activity; avoid duplication.

## Implement

1. Ensure appId/namespace and source package consistently use `com.tutornet.app` (or document the existing package if intentionally different).
2. Confirm one `MainActivity` hosting Compose and a minimal app navigation shell. Do not prematurely instantiate all feature routes or modules.
3. Use an existing or minimal Compose Material 3 theme; **do not invent Figma color tokens** before design extraction. Keep a clear place for verified tokens.
4. Define route/entry boundary, app-level error placeholders and preview/test approach as needed; avoid adding Hilt/Retrofit/Room without concrete use and compatible dependency versions.
5. Keep existing `AGENTS.md` and documentation; create only justified files. Keep local.properties, build outputs, keystores, tokens and machine-specific paths out of Git.
6. Add/verify a minimal Compose instrumentation or unit smoke test in the current test setup if feasible.

## Definition of Done

- Gradle sync succeeds.
- `./gradlew :app:assembleDebug` succeeds (Windows: `gradlew.bat :app:assembleDebug`).
- Debug app launches on the Android emulator and shows a temporary foundation screen; no fabricated Figma UI claim.
- Folder ownership is consistent, no direct networking in Compose, no backend/infrastructure modifications.
- Report exact dependencies and versions from actual Gradle files, changed paths, commands and results.

**Do not implement Login/Feed in this task.** The next PR handles Figma UI and mock behavior.
